# Сопроводительное сообщение

Добрый день!

Выполнил MVP AI-помощника для подготовки товарных карточек контрольно-измерительных приборов.

Реализованы веб-форма и JSON API, интеграция с GigaChat API, Structured Output по JSON Schema, обработка неполных данных и многоуровневая проверка результата.

Для снижения риска галлюцинаций приложение сначала формирует реестр разрешённых фактов только из входного JSON. Технические характеристики вообще не генерируются моделью — они копируются напрямую из `specs`. После генерации выполняется детерминированная проверка новых числовых значений и отдельный факт-чек запроса к LLM: каждое утверждение проверяется относительно реестра исходных фактов. Если обнаружены неподтверждённые сведения, текст автоматически перегенерируется; при повторной неудаче сервис возвращает ошибку вместо сомнительной карточки.

API-ключ хранится только в локальном `.env`, исключённом из Git. В репозиторий входит только `.env.example` без секретов; добавлен отдельный pre-push скрипт проверки возможных секретов.

Основное ограничение MVP: LLM-факт-чек не является формальным доказательством истинности, поэтому финальная публикация всё равно предполагает проверку контент-менеджером.
